## Post 1 — "the company is the memory" (day 1 build, after core loop worked)

Your agents are employees. Calliope is the company. 🏗️

Built for @SibylLabs' hackathon over the weekend — a workforce whose ENTIRE
institution lives in Sibyl Memory: the charter, roles, handoff routes, client
standards, the vendor book, even the obligations mid-flight.

Delete the memory → there is no company. Every boot refounds from nothing and
repeats the mistake the last session learned to ban.

The rule everyone quotes is right: memory must be load-bearing. So we made the
org itself the memory — no role table, no vendor list, no policy in code.

What that buys you:
• kill every process — fresh boot reconstitutes the org in seconds
• hot-swap the model — the work survives, the brain doesn't matter
• vendors get banned into the vendor book, and the NEXT session cites the ban

The deletion test is an actual test: `npm test` spawns real processes and
asserts the collapse. 18/18. Code: (repo link)
